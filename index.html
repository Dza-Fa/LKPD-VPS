Shared Hosting

Layanan hosting di mana satu server fisik digunakan secara bersama-sama oleh banyak pengguna atau website. Sumber daya seperti CPU, RAM, dan penyimpanan dibagi bersama. Harganya sangat terjangkau dan ramah pemula, namun performa website Anda dapat terpengaruh jika website lain di server yang sama mengalami lonjakan trafik yang tinggi.

Dedicated Server

Layanan penyewaan satu server fisik secara utuh dan eksklusif untuk satu pengguna tanpa berbagi dengan pihak lain. Seluruh sumber daya server didedikasikan penuh untuk Anda, sehingga menawarkan performa maksimal dan tingkat keamanan tertinggi, tetapi memiliki biaya sewa yang mahal serta memerlukan keahlian teknis khusus untuk pengelolaannya.

Amazon Lightsail

Layanan Virtual Private Server (VPS) dari AWS yang dirancang khusus agar mudah digunakan oleh pemula, mahasiswa, maupun pengembang untuk proyek skala kecil hingga menengah. Menawarkan paket harga tetap (flat-rate) yang prediktif serta kemudahan deployment instan untuk berbagai platform populer (seperti WordPress, Linux, atau Node.js).

Amazon EC2 (Elastic Compute Cloud)

Layanan komputasi awan (cloud computing) berbasis Infrastructure as a Service (IaaS) dari AWS yang menyediakan kapasitas virtual yang sangat fleksibel dan dapat disesuaikan (scalable). Pengguna memiliki kontrol penuh atas sistem operasi, jaringan, dan keamanannya dengan sistem pembayaran sesuai pemakaian (pay-as-you-go).
